## 二、四处与方案稿不一致的地方（均已按代码事实处理）

1. **toast 占位是 7 个，不是 8 个**（稿件给的 8 个是计数偏差；7 处位置逐个核过）。
2. **`plugin_market_package_hash_test.dart` 稿件写「已存在」，实际不存在** —— 本轮新建。
3. **FIX-07 选了「接线」而不是「删除」**：三个扩展点连同单测都在、文档还把它们列为收益，删掉等于承认文档一直不实。
   另外稿件附录 A 方案要求「下架时停答题插件 overlay」，**仓库里没有这个 API**（全仓 grep 无命中），
   因此该项未做，改为「审计轨迹 + 真实 `validate()` 拒绝空条目」—— 没有假装做了。
4. **FIX-09 的「折叠为独立分组」改成「沉底 + 标记 + 无安装入口」**：同样达到「用户不会被占位条目误导」的效果，改动更小。

## 三、明确未做（附理由）

- FIX-06 提到的「扩展页显示一次性提示横幅」：失败状态已可查（`lastPersistFailed`）且已进
  `AppLogger` 的 system 频道（App 日志页可见），但**没有**在扩展页新增横幅 —— 需要额外的重建触发点，暂不值当。
- 稿件本身的问题（计数偏差与范围缺口，例如未覆盖同目录的 `server_ops` 插件）建议出 v1.1 修正；
  不影响按稿施工。
