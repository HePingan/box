## 一、仍有价值未做（按性价比）

判断标准与上一版一致：**「没做」不等于「欠债」**。只有「用户看得见、且无
『有意不做』标记」的才排在这里。本轮之后**真正的欠债已清零**，
下面全是「可选新增」，不再是债。

### 1. 水印中文支持（P2，0.5 天）

- **现状**：`image` 包只内置 `arial14/24/48` 三款位图字体，**没有汉字字形**。
  实测 `drawString("中文")` 的深色像素数为 **0**（不是难看，是一个都不画）。
  UI 已在输入框下方明示这个限制（`image_watermark_panel.dart`）。
- **代价**：改用 `dart:ui` 的 `TextPainter` 渲染文字成透明 PNG 再合成；
  `dart:ui` 自带系统中文字体，不必打包 TTF。
- **风险**：`TextPainter` 依赖 Flutter 引擎，纯 Dart 单测跑不了，
  需拆成「文字→图片」与「图片→合成」两段，只测后者。

### 2. 趣味游戏（P2，分批做，先 1 天）

- **现状**：`趣味游戏` 分类**可见 1 条、未接线 7 条**，是唯一「看着像功能
  但只有一个入口」的分类。
- 7 条全是纯本地算法、零依赖：扫雷 / 2048 / 数字华容道 / 五子棋 / 贪吃蛇 / 迷宫 / 数独。
- **建议**：先做 2048 + 扫雷（1 天），观感 OK 再决定继续。
  不建议一次 7 个 —— 游戏最怕「数量够了但每个都不好玩」。
- 不推荐：五子棋（要 AI 对手，「跟谁下」是产品问题）、数字华容道（与 2048 同属滑块类）。

### 3. 静默失败逐条标注（P2，0.5 天，**只查不改**）

- 48 条是脚本纯文本匹配的**上界**，抽样 2 处均为误报
  （`announcement_tab` 的 catch 设了 `_error`；`book_source_tab` 的 catch `skipped++`
  且最终如实提示）。
- 建议先产出「真静默 / 有留痕 / 有意为之」清单，**改之前先知道哪些是真的**。
