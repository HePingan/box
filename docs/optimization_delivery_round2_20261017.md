## 一、本轮改了什么

### 1. 音乐入口落地阶段 1（在线音频下载后播放）

按 `docs/music_area_entry_plan.md` 的「B→A」拍板落地，播放能力 **100% 复用
remote_storage**（`video_player` + `chewie` + 中继），不新增任何播放库。

顺带收掉占位页时期的三个问题：

| 问题 | 后果 |
|---|---|
| `_urlController` 从不 `dispose()` | 监听链泄漏 |
| 裸 `Dio()` **零超时** | 站点挂住时用户永远停在「下载中…」，只能杀进程 |
| 下载的音频落在临时目录**根**下且不删 | 每播一首留一份（几 MB～几十 MB） |

入口文案同步改成事实：副标题「播放器开发中」→「在线音频播放」；关于页不再
说它是占位页（本地扫描阶段 3 未做，不拿它当卖点）。契约测试从「锁占位」改成
「锁不承诺做不到的事」。

### 2. 漫画导出的两类真实隐患

**(a) 解压产物落在系统临时目录** —— `ComicBook.pages` 把它当**长期引用**，
系统清临时目录（低存储、重启清理）后书架上书还在、点开全是白页；而备份只存
元数据不存图片，等于丢了。

- 改落 `应用文档目录/comic_imported/<时间戳>/`（`importRoot` 可注入，测试隔离）
- 新增 `disposePages()`：删书时清理解压副本，只删 `importRoot` 内的目录
  （`p.isWithin` 按路径段判断，不是字符串前缀），用户原包/文件夹一律不碰
- 删除确认按 `sourceType` 分开说：`file` 类型明说「解压副本会清理」
- 阅读器页图缺失时不再只显示破图标，而是说明原因 + 给出「重新导入」这一步
  （老版本导入的书已经指向被清掉的临时目录，用户会真的撞上）

**(b) 整本 CBZ 被解压两遍**（第一轮已修）—— `extractPages()` + `extractCover()`
各调一次 `extract()`，第一份产物（全部页图）直接成垃圾。

### 3. 九宫格切图：图片工具第一个真正可用的

图片工具分类 9 条里有 8 条未接线。九宫格是其中唯一**不需要新增三方依赖**就能
做实的（切图本质是按矩形裁一块再编码，`dart:ui` 够用）。

- `domain/local_tool_image_grid.dart`：纯几何计算，不碰 Canvas
  - 除不尽时余数**并入最后一块**（均摊会在中间产生 1px 缝）
  - 相邻块首尾相接，几块拼回去严格等于原图尺寸
  - 切块数比像素还多时抛错，而非产生 0 宽块
  - `suggestGrid`：横图 2×4 / 竖图 4×2 / 正方形 3×3
- `presentation/image_grid_panel.dart`：选图 → 调几何 → 裁 → 存相册
  - 走 `LocalToolCard` 外壳（布局契约测试覆盖）
  - 部分保存失败如实报「只保存了 N/M 张」，不报「已保存」
- 单测 17 条锁几何边界

### 4. 冷启动不再为「诊断」白等

`AppBootstrap.initialize()` 返回之前，`main.dart` 只画一个转圈 —— **里面每个
await 都是用户白等的时间**。两处纯诊断能力被移出关键路径：

| 项 | 原来 | 现在 |
|---|---|---|
| `_attachWindowDiagnostics` | 两个平台通道往返，且 blocking | `addPostFrameCallback` 后执行 |
| `DiagnosticHeader.prime` | `PackageInfo` 平台通道，最坏 2 秒超时 | `unawaited` 后台预取 |

顺序仍是 logger 之后（原生回放的早期事件不会丢）。配**源码级闸门**锁住 ——
运行期测试发现不了这类回归：改回 `await` 全量测试照样全绿。

### 5. 预览导出临时文件不再只写不清

`box_preview` 目录以前只写不删：预览里每导出一次留一份（预览上限 20MB，
大图/PDF 攒几次就是几百 MB）。现在分享外出后删掉自家那份，每次写入前收一次
上限（>20 个文件或 >100MB 时按 mtime 删到一半）。
