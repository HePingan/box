# 漫画源 Step 1：源自检（1.20.60 / 317）

**一句话**：把「包子漫画」这份 Legado 漫画书源当配置装进 App，用手机上的真 WebView 把
**搜索 → 打开一本书 → 打开第一章取图** 跑一遍，逐项给出「通过 / 失败 + 原因」。

这一步不是"能看漫画"，它的价值是**把未知变已知**：章节页在我们两台服务器上都是 502，
只有手机上能问出真相。

---

## 一、为什么架构只能是"App 内 WebView 取页"

实测证据（2026-09-27，两台机房机器 175 / hpa888 都试过）：

| 环节 | 实测结果 | 说明 |
|---|---|---|
| 搜索页 | **HTTP 403 + `__gatekeeper_challenge`** | 纯请求过不去；两台机房 IP 一律 403 |
| 搜索页（真浏览器） | ✅ 挑战能过，`.comics-card` 命中 **77 条** | 真实 DOM 与书源类名完全对得上 |
| 详情页 + 章节列表 | ✅ | 标题「航海王」，章节 **1211** 条 |
| 分类接口 | ✅ `/api/bzmhq/amp_comic_list` 200 JSON | |
| 封面图 | ✅ **无防盗链**（不带 referer 也 200，33KB jpeg） | `Image.network` 能直接取 |
| **章节阅读页** | ❌ **一律 502** | 更换镜像域名、从详情页点击进入（带 Referer + cookie）都一样 |

⇒ **服务端代取不可行**（JS 挑战 + 机房 IP 502，两处都是死穴）。
⇒ 唯一可行路径：**App 内的 WebView**。它既能过挑战，又能跑书源里的 `<js>` 段 ——
Dart 没有 JS 求值能力，WebView 有（Legado 自己也是这么干的）。

## 二、这一步做了什么（代码位置）

| 文件 | 作用 |
|---|---|
| `lib/features/comic/domain/sources/seed_comic_source.dart` | 书源 JSON 原样内置（**配置数据**，Step 4 改成可热更新） |

| `lib/features/comic/domain/comic_source_diagnostics.dart` | 自检流程：三步、逐步给结论、每步带页面标题与最终地址 |
| `lib/features/comic/presentation/comic_source_webview_target.dart` | 真机取数：驱动一个**离屏 1×1 WebView** |
| `lib/features/comic/presentation/comic_source_check_page.dart` | 自检界面 + **「复制结论」**（手机上贴回来就是证据） |
| `lib/features/comic/presentation/comic_library_page.dart` | 漫画库右上角加「源自检」入口；**删掉那句假文案** |

坏文案（原来）：「在线漫画源请到扩展页安装」—— 扩展页里根本没有漫画源可装（全仓无此扩展点）。
现在指向真的能用的东西：「在线漫画源还没接入 —— 右上角「源自检」可以看看内置源在这台手机上通不通。」

### 界面上的三条硬规矩

1. **每步失败必须写原因**：超时 / HTTP 状态 / 选择器 0 命中 / 规则不认识，四类分开说；
   还会把**页面标题**带出来 —— 502 这种错误只看"命中 0"是看不出来的。
2. **配置错误 ≠ 站点没数据**：规则解析不了会说「规则不认识：「…」—— 这是配置问题，不是站点问题」，
   不会被混进"打不开页面"里带偏排查方向。
3. **跑到一半就失败**：后两步标「跳过」，不是「通过」；拿到图就当场显示一张（能显示 = 图片链通）。

## 四、规则引擎：支持到哪、哪里不一样（不藏着）

支持（这份源真实用到的形状）：
- 选择器：`class.a b c`（**同一元素**上的多个类名）· `tag.amp-img` · `id.x` · 裸标签名 `amp-img`；
- 索引：`class.x.0`、`tag.amp-img.0`、单独一段 `.0`；
- 分段：`@` 分隔，逐段往里找（后代）；
- 取值：`text` / `html` / 属性名（`src` / `href` / `data-src` …）；
- **JS 段**：`<js>…</js>` 与 `@js:…` 在页面里真跑，配套 `java.*` 垫片（`getElements` / `t2s` / `baseUrl`）。

**明确没做**：
- `java.t2s` **繁转简未实现**（没词表），拿到的繁体就是繁体 —— 界面上写了这句，不冒充已转换；
- 这份源的 `ruleBookInfo.tocUrl` 第 3 段是**它自己的笔误**（`@harf@`，应为 `@href@`）：
  本 App 不照抄，章节链接改从详情页取（实测 1211 条正常）；
- Legado 的其它语法（正则、模板变量、`ajax`、登录态等）不在范围内。
