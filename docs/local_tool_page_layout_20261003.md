# 本地工具页版式：卡片撑满 + 内容居中（2026-10-03）

## 改前（实测）

用一次性 widget 探针（`tmp_height_probe_test.dart`，跑完即删）在 360×780 的典型手机上量了
28 个本地工具页面「内容占到哪一行」。内容区 = 屏高 780 − 顶部返回条 42 = **738px**：

| 页面 | 内容占到 | 下方空白 |
|---|---|---|
| 指南针 / 水平仪 | 243px | **69%** |
| 计时器 | 289px | 63% |
| 全屏时钟 / 随机数 | 317~319px | 59% |
| 秒表 | 339px | 57% |
| BMI / 进制 / 大小写 / 时间屏幕 / 摩斯 | 345~347px | 56% |
| URL 编解码 | 361px | 54% |
| **分贝仪** | 373px | **52%** |
| 科学计算器 | 453px | 42% |
| 文本编辑器 | 565px | 28% |
| 颜文字 | 716px | 8% |

28 个**全都有留白**，中位约 50%。分贝仪（用户截图那个）52%，是典型而不是特例。

## 根因（一处，不是二十处）

`local_tools_registry.dart` 的外壳是：返回条 + `Expanded(SingleChildScrollView(padding, child: 面板))`，
而每个面板都是 `LocalToolCard` —— **按内容高度自适应、顶部对齐**。内容一短，白卡片就浮在
屏幕上半部，下半屏只剩背景色。换哪个工具都一样。

## 改法

1. **外壳**（`local_tools_registry.dart`）：`LayoutBuilder` + `ConstrainedBox(minHeight: 可视高度 − 32)`
   → 卡片撑满内容区。内容真的超过一屏时 minHeight 不起作用，照旧滚动。
2. **卡片**（`local_tool_panels.dart`）：`mainAxisAlignment: MainAxisAlignment.center`
   → 卡片比内容高时，把「标题 + 内容」这块整体居中；内容本来就满时零位移。
3. **三个最空的工具补上"该有的主体"**：
   - **指南针**：盘面 180 → 自适应 200~300（360 宽屏上是 284）；改成**盘面转、顶部指标固定**
     （以前是指针转、盘面不动，看着像电子罗盘图标）；盘内给角度 + 八方位名；「北」标红；
     刻度长度随盘面缩放；加内圈。
   - **水平仪**：气泡 200 → 自适应；加两轴数值块（前后倾 / 左右倾，水平时变绿）+ 提示条
     （没水平时说清"气泡进中圈就算水平"，不只丢一句"未水平"）+ 零点误差说明；气泡加外圈。
   - **分贝仪**：大数字 40 → 64 并按分档上色；细进度条 → **0~120 色带**（绿/蓝/橙/红四段 +
     当前读数指针 + 峰值刻线 + 0/30/60/90/120 刻度）；峰值与平均值块（平均用既有
     `sv.averageDb`）；**常见噪音参考表**（沙沙 20 / 冰箱 40 / 正常交谈 60 / 吸尘器 75 / 电钻 100，
     超过哪一行就高亮哪一行，并写「已超过「正常交谈」」）。
   - 没在测量时：大数字、峰值、平均**三处都显示 `--`**，不拿 0 或上次的读数冒充（护栏用例钉住）。

## 落点

- `lib/features/local_tools/presentation/local_tools_registry.dart` — 外壳撑满
- `lib/features/local_tools/presentation/local_tool_panels.dart` — 卡片居中 + 三个面板 + 三个展示件
  （`_DbScaleBar` / `_DbStatTile` / `_DbReferenceTable` / `_TiltTile` / `_LevelHint` / `_CompassDial`）
- `test/features/local_tools/local_tool_page_layout_test.dart` — 6 条：28 个工具卡片撑满且不抛异常 ·
  短面板上下留白差 ≤ 40px（居中）· 分贝仪静止态三处 `--` 且参考表齐全 · 按钮可用性 ·
  指南针/水平仪没数据时是加载态而不是 `0.0°`

## 实测（改后）

口径：`flutter analyze --no-fatal-infos`（回到基线 28）+ `flutter test --exclude-tags live`（CI 口径）。

- 28 个工具的**卡片高度都 ≥ 内容区 − 48**（撑满），且构建无异常。
- 短面板上下留白差 ≤ 12px（= 居中）：指南针 283.5 / 295.5、水平仪同、秒表 235.5 / 247.5、
  随机数 246.5 / 258.5（差值恒等于卡片底部 12px 内边距）。
- 分贝仪内容 373 → **690px**（卡片 732，几乎占满）。

## 没做（留档）

- 其余 24 个工具只吃到外壳红利（卡片撑满 + 居中），**内容本身没动** —— 文字/转换类工具的
  留白是正常的，硬塞东西只是把空白换成噪音。
- 秒表 / 计时器 / 全屏时钟的大号数字 + 环形进度：本轮未做，需要时再单独立项。
